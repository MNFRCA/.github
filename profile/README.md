# Minnesota FRC Advocacy
MNFRCA is a student-led group interested in lobbying the Minnesota Legislature to increase state support for Robotics teams in Minnesota. By lowering the financial barrier for youth robotics Activities, Minnesotans gain opportunity to help develop the next generation of STEM Leaders and help grow a community that encourages creativity and exploration for the youth.
